# 上岸雷达 · 校招岗位智能匹配平台

> 一款面向应届生的多用户校招求职工具：填写自己的求职画像，系统自动从 5400+ 条岗位库中按匹配度排序，推荐最合适的校招岗位。

## 产品定位

校招季岗位信息分散在各企业官网与飞书汇总表中，数量庞大、格式不一，求职者难以按自身专业、意向方向与目标城市快速筛选。上岸雷达把「海量翻表」变成「按画像精准推荐」。

## 核心功能

| 模块 | 说明 |
|------|------|
| 注册登录 | 昵称 + 口令，首次输入即注册，换设备用同样组合找回数据 |
| 求职画像 | 自由填写专业、意向方向、目标城市、是否接受笔试 |
| 岗位库 | 5400+ 条全方向校招岗位，每日自动更新 |
| 智能匹配 | 按个人画像对每条岗位重新计算匹配分，附匹配理由 |
| 投递跟踪 | 记录投递进度、设置提醒、查看转化漏斗 |

## 匹配算法

对每条岗位，按登录用户的求职画像动态计算匹配分（40–95 分）：

- **方向命中**：意向方向命中岗位类别或角色关键词 +22 分
- **城市匹配**：目标城市命中 +12 分，未命中 −10 分，留空视为不限 +8 分
- **专业相关**：专业与岗位行业关键词相关 +8 分
- **自定义关键词**：命中岗位文本 +6 分
- **笔试意愿**：不接受笔试的岗位含笔试 −18 分并提示

匹配分随用户画像实时变化，实现「千人千面」的岗位推荐。

## 技术栈

- **后端**：Python / Flask
- **数据库**：SQLite（多用户数据隔离）
- **前端**：原生 HTML / CSS / JavaScript
- **数据源**：飞书《27 届校招汇总表》批量导入 + 每日自动同步

## 项目结构

```
.
├── app.py                # Flask 后端（登录 / 画像 / 匹配引擎 / 投递记录 API）
├── static/
│   ├── campus.html       # 岗位库看板（首页）
│   └── index.html        # 投递记录工具（/tracker）
├── requirements.txt      # Python 依赖
└── .gitignore
```

> 注：`campus_data.json` 为岗位数据（5400+ 条），由飞书同步脚本每日生成，不入库。运行前需自行生成或从线上环境获取。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 准备密钥文件 campus_secret.json（不提交，需自行创建）
#    {"accessKey": "你的口令"}

# 3. 启动
python app.py
# 访问 http://localhost:3000
```

## 数据说明

- 岗位数据来自飞书《27 届校招汇总表》，覆盖 13 类方向（产品类、技术研发类、设计类、运营类、管培生等）。
- 飞书来源记录未逐条核验通道状态，匹配分为规则计算，投递前请自行确认。
- 用户投递记录存储在本地 SQLite（`data.db`），不随仓库提交。
